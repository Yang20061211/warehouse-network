# 城际仓网规划系统

数据结构课程设计 · 第二组

## 一、项目简介

项目模拟 30 个城市仓储节点之间的光纤网络：用最小生成树计算最低铺设成本，并提供任意两仓之间的路径查询。系统使用 Java Swing 实现，包含三部分：

1. **双向循环链表**管理城市坐标，支持增删改查和按距离排序；
2. **邻接表**存储带权无向图，边权 = 经纬度欧氏距离（保留 2 位小数）；
3. **Prim / Kruskal** 求最小生成树，**Dijkstra** 在 MST 拓扑上查询任意两城路径。

系统包含管理员和查询员两种角色。城市数据改变后会同步重建图、MST 与路径缓存。

## 二、运行方式

### 环境要求

- Windows 10/11、macOS 或 Linux
- JDK 17 或更高版本（终端执行 `java -version` 可查看）
- 不需要任何第三方依赖，不需要联网

### Windows 双击启动（推荐）

1. 双击 `运行系统.bat`；
2. 首次启动会自动编译，之后直接打开登录窗口；
3. 修改源码后，双击 `重新编译.bat` 可清理并重新构建。

### macOS / Linux 双击启动

1. 双击 `运行系统.command`；
2. 首次启动会自动编译，之后直接打开登录窗口；
3. 如果系统提示无法打开，右键点击 →「打开」，或在终端执行：

```bash
chmod +x 运行系统.command 重新编译.command
./运行系统.command
```

## 六、设计要点

- **带头结点的双向循环链表**：空表时 `head.next == head.prev == head`；尾插 O(1)；已定位结点的删除 O(1)。
- **按距离排序**：链表就地插入排序，先摘链、预计算距离、逐个插入，稳定且 O(n²)。
- **邻接表**：30 个顶点 / 435 条无向边 / 870 个边结点；无向边在两个端点各存一次。
- **MST**：Prim 用 O(V²) 数组实现，Kruskal 用排序 + 并查集；两种算法总权值均为 117.97。
- **最短路径**：按作业要求以 Prim 生成树为拓扑运行 Dijkstra；查询重复 250 次取平均，实测在微秒级。
- **快速刷新**：一次完整的“完全图 + Prim + Kruskal + MST 缓存”重建约 0.09 ms（本机 300 次平均）。

## 七、常见问题

**双击后窗口一闪而过？**

Windows 请在命令提示符中执行 `运行系统.bat`，macOS / Linux 请执行 `./运行系统.command`，以查看具体编译错误；通常是 JDK 未安装或版本低于 17。

**`java -version` 正常但 `javac` 找不到？**

需要安装 JDK（而不是只有 JRE）。项目按 Java 17 目标编译。

**修改城市后数据保存在哪？**

`data/cities.txt`，UTF-8 编码，格式为「城市名 经度 纬度」。删除该文件会重新载入内置 30 城。

**为什么 MST 路径比“完整网络”路径长？**

作业要求基于生成树拓扑查询，树上路径唯一；完整网络可能走更短的直达边，所以系统把完整网络作为对比模式提供。

更多设计细节、复杂度分析、性能数据和四问详解，见 [`docs/实验报告.md`](docs/实验报告.md)。
